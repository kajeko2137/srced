# Srced IDE

A console-based IDE built with Rust using `ratatui` and `crossterm`.

## Components

- **ConsoleRenderer**: Handles terminal initialization, raw mode, and drawing frames.
- **App**: Manages application state, event loop, and component orchestration.
- **Editor**: (Planned) Main text editing component.

## Getting Started

Run the project with:
```bash
cargo run
```

Press `q` to quit.
